The text is created in `lettering()` in the Python script. It places each letter along the panel at `ax = xcur + a*ux` and `bx = xcur + c*ux`, which runs towards +X. The pediment faces +Y. A viewer standing outside, looking back at it with Z up, has their right-hand side on −X. So text laid out towards +X reads right-to-left from outside, with every letter mirrored. There was no mirror transform, wrong extrusion direction or flipped workplane. The reading axis was simply pointing the wrong way.

I missed this because my own preview renderer drew +X on the right-hand side, which is itself a mirror view. I've now checked with a view that puts −X on the right.

**2. The change**
In `lettering()`, the reading coordinate is now mapped to X = −u:

```python
# before
ax, az = xcur + a * ux, zc - hz / 2 + b * hz
bx, bz = xcur + c * ux, zc - hz / 2 + d * hz
# after
ax, az = -(xcur + a * ux), zc - hz / 2 + b * hz
bx, bz = -(xcur + c * ux), zc - hz / 2 + d * hz
```
